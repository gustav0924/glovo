# Reto IA - Glovo

Este repositorio contiene la solución desarrollada para el Reto de Inteligencia Artificial de Glovo. El proyecto incluye un análisis exploratorio de datos (EDA), ingeniería de características, modelado predictivo y una interfaz de visualización de resultados.

## Estructura del Proyecto

El repositorio se organiza de la siguiente manera:

* **Glovo_RIA_v2.ipynb**: Notebook principal utilizado para la presentación final. Contiene el flujo completo de trabajo consensuado por el equipo.
* **Glovo.ipynb**: Notebook con una propuesta alternativa y experimentación adicional.
* **app.py**: Dashboard interactivo desarrollado con Flask para la visualización de métricas y resultados del modelo.
